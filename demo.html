Email Capture Plugin

Same server. Different files. One script tag per page.

Page A — sends ebook.pdf (inline, light)

Developer sets data-file="ebook.pdf". User enters email, gets that file.

<script src="http://localhost:8000/plugin.js" data-website="mysite" data-file="ebook.pdf" data-title="Download our free eBook" data-btn="Send me the eBook" data-theme="light" data-position="inline"> </script>

Live Preview ↓

Page A2 — sends vmx-installer.iso with doc link & specs

Optional attributes below only affect the follow-up email — the widget itself looks the same. Omit any of them and that section just won't show in the email.

<script src="http://localhost:8000/plugin.js" data-website="mysite" data-file="vmx-installer.iso" data-title="Download VMX Installer" data-btn="Send me the ISO" data-theme="light" data-position="inline" data-doc-link="https://docs.example.com/vmx-setup" data-spec-module="VMX Hypervisor" data-spec-version="v10.0-Stable" data-spec-arch="x86_64 (64-Bit)"> </script>

Live Preview ↓

Page B — sends guide.pdf (floating, dark)

Same server, different file. Floating button at bottom-right.

<script src="http://localhost:8000/plugin.js" data-website="mysite" data-file="guide.pdf" data-title="Get the complete guide" data-btn="Get guide" data-theme="dark" data-position="bottom-right"> </script>

👉 See the floating button at bottom-right of this page.

Page C — sends template.zip (popup)

Any file type works — pdf, zip, docx, etc. Center popup style.

<script src="http://localhost:8000/plugin.js" data-website="mysite" data-file="template.zip" data-title="Free template pack" data-btn="Get templates" data-position="center-popup"> </script>
